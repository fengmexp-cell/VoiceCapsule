# VoiceCapsule V2.0.0 使用說明

**輕量化・離線優先・隱私至上・語音影視轉文字工具**

> 想到就說，說完就有文字。不想打字時，直接說就可以。

VoiceCapsule 是一套以本機語音辨識為核心的語音輸入與音訊／影片轉文字工具，支援 Windows 與 Ubuntu Linux。

使用電腦麥克風即可將語音轉換成文字，也可以匯入音訊或影片檔案，產生逐字稿、字幕與帶有時間軸的文字檔案。

VoiceCapsule 以本機執行為優先，不需要訂閱雲端語音服務。正式版也整合了第三方 API 功能，使用者可以依照自己的需求選擇是否使用線上服務。

## 1. VoiceCapsule 是什麼？

VoiceCapsule 不只是一般的語音輸入工具，也可以處理音訊與影片中的語音，將內容轉換成文字及字幕。

### 核心特色

- **本機語音辨識：** 使用 Faster-Whisper 在本機執行語音辨識。
- **自動判斷語言：** 不必因為使用中文介面，就將語音輸入限制為中文。
- **多種 Whisper 模型：** 提供 small、medium、large-v3、large-v3-turbo 等模型。
- **跨軟體文字輸入：** 辨識完成後，可將文字輸入到其他可接受文字輸入的軟體。
- **字典修正：** 提供常見錯誤與個人字典，協助修正常見辨識錯誤。
- **音訊／影片轉文字：** 將媒體中的語音轉換成文字。
- **多種輸出格式：** 支援 TXT、SRT、LRC。
- **離線優先：** 一般本機語音辨識不需要依賴付費雲端語音服務。
- **正式版 API 功能：** 使用者可自行設定支援的第三方 API。

VoiceCapsule 的設計目標，是讓語音輸入更方便，減少打字的負擔，同時讓使用者能夠依照自己的習慣調整辨識結果。

## 3. 麥克風語音輸入

VoiceCapsule 可以直接使用電腦麥克風進行語音輸入。

### 使用方式

1. 將文字輸入游標放到目標軟體的輸入位置。
2. 使用 VoiceCapsule 開始錄音。
3. 預設錄音時間為 10 秒，可以在系統設定中調整。
4. 錄音過程中也可以提前停止。
5. 錄音結束後，VoiceCapsule 進行語音辨識。
6. 辨識完成後，文字可以輸入到目標軟體。

使用時不需要一直按住按鈕說話。

### 錄音會產生什麼檔案？

麥克風語音輸入會產生：

- **WAV：** 麥克風錄音檔。
- **TXT：** 語音辨識後的文字檔。

這些檔案存放在 `audio_temp/` 暫存資料夾。

TXT 可以作為辨識結果的備用紀錄。例如，想找回先前說過的文字，或檢查輸入內容是否完整時，可以查看文字檔。

不過，`audio_temp/` 是暫存位置，不適合用來長期保存重要文件。

**如果文字檔案還需要日後使用，請先複製或另存到其他資料夾。**

## 4. 可以輸入什麼語言？

VoiceCapsule 使用 Whisper 語音辨識模型，能夠辨識多種語言，並自動判斷語音來源語言。

例如：

- 說中文 → 辨識成中文
- 說日文 → 辨識成日文
- 說越南文 → 辨識成越南文
- 說印尼文 → 辨識成印尼文

中文介面只是使用者介面的語言，並不代表 VoiceCapsule 只能辨識中文。

實際辨識結果會受到模型、語音內容及錄音環境影響。

## 5. 語音辨識準確度

語音辨識效果除了模型本身，也會受到實際錄音環境影響。

常見的影響因素包括：

- 麥克風品質
- 麥克風與說話者的距離
- 環境噪音
- 空間回音
- 說話速度
- 口音與發音方式
- 多人同時說話
- 實際收音品質

如果希望得到較好的辨識結果，建議使用品質較好的麥克風，並盡量減少環境噪音。

外接麥克風通常可以提供比電腦內建麥克風更好的收音效果，但實際效果仍取決於設備與使用環境。

## 6. 音訊與影片轉文字

VoiceCapsule 可以將音訊與影片中的語音轉換成文字。

### 基本操作方式

1. 開啟「音訊轉文字－影片轉文字」操作視窗。
2. 按下「選擇檔案」。
3. 選擇要處理的音訊或影片。
4. 選擇需要的處理功能。
5. 等待處理完成，查看輸出結果。

如果需要一次處理多個檔案，可以使用「批次處理檔案」。

處理過程中，可以使用「取消鍵」取消正在執行的處理工作。

### 音訊／影片輸出格式

VoiceCapsule 提供下列輸出格式：

| 格式 | 說明 | 適用情境 |
|---|---|---|
| TXT | 純文字逐字稿 | 閱讀、編輯、複製、保存內容 |
| SRT | 帶有時間資訊的字幕 | 影片字幕、字幕編輯、影片後製 |
| LRC | 帶有時間軸的歌詞／文字 | 歌詞製作及需要時間點對應的文字 |

可依照實際需求選擇需要的輸出格式。

音訊／影片轉錄產生的文字檔與相關紀錄，存放在 `logs/` 資料夾。

### 中文翻譯英文

VoiceCapsule 也提供將音訊或影片中的語音直接轉換成英文文字的功能。

這項功能使用 Whisper 的語音翻譯能力，並不是單純將已經產生的中文文字再交給翻譯程式處理。

更多說明請參閱「翻譯功能」。

## 7. 資料夾與暫存檔案管理

VoiceCapsule 將麥克風語音輸入與音訊／影片轉錄結果分開保存。

### `audio_temp/`：麥克風錄音與暫存資料

這個資料夾主要存放麥克風錄音產生的 WAV、TXT，以及相關暫存資料。

在一般語音輸入時，產生的檔案可以暫時留在這裡，供使用者查看辨識結果。

但是，當使用者進行音訊轉文字或影片轉文字時，VoiceCapsule 會在每處理完一個檔案後，清理相關暫存資料並釋放處理資源。

因此，`audio_temp/` 中原本存在的錄音檔和文字檔，也可能因為自動清理而被刪除。

**重要提醒：如果 `audio_temp/` 裡的文字還需要閱讀、編輯、寫作或日後使用，請先將文字複製或另存到其他位置。不要只把唯一的副本留在暫存資料夾中。**

### `logs/`：音訊／影片轉錄結果與相關紀錄

這個資料夾用來保存音訊／影片處理產生的文字檔及相關紀錄。

`logs/` 與 `audio_temp/` 的用途不同。

每完成一個音訊／影片檔案後，程式清理工作暫存時，不會因此自動清空整個 `logs/` 資料夾。

如果需要保留轉錄結果，可以將檔案另存或複製到自己的文件資料夾。

### 系統設定中的垃圾桶按鈕

VoiceCapsule 的系統設定中提供清除存檔的按鈕。

使用這項功能時，會清除相關保存資料，包括 `logs/` 中的檔案。

因此，**按下清除按鈕前，請先確認是否還有需要保留的文字或轉錄結果，並先做好備份。**

## 8. 自動資源清理與「重置記憶體」

VoiceCapsule 在處理音訊／影片時，採用以下方式管理資源：

**完成一個檔案 → 清理該次處理的暫存資料 → 釋放相關處理資源 → 再處理下一個檔案。**

這種設計是為了提高長時間及反覆處理音訊／影片時的穩定性，避免暫存資料與處理資源不斷累積。

模型本身可以在需要時維持載入，避免每處理一個檔案就重新載入完整模型。

### 「重置記憶體」的作用

「重置記憶體」是比較完整的資源釋放操作，主要包含：

- 釋放目前載入的模型。
- 釋放可釋放的 RAM。
- 使用 GPU 時，釋放可釋放的相關 VRAM。
- 釋放處理程序使用的資源。
- 清理相關工作暫存。

執行後，如果再次使用語音辨識或音訊／影片處理，就需要重新載入模型。

另外，作業系統可能保留部分已配置的記憶體，因此按下重置記憶體後，Windows 或 Linux 顯示的記憶體使用量不一定會立即降到非常低。

**自動暫存清理、重置記憶體，以及系統設定中的清除存檔，是不同的操作。**

## 9. 文字輸入到其他軟體

VoiceCapsule 的語音輸入不限制在 VoiceCapsule 自己的視窗。

辨識完成後，可以將文字輸入到其他可接受文字輸入的軟體，例如：

- 瀏覽器
- Word
- Google Docs
- Notion
- 電子郵件
- 程式碼編輯器
- 筆記軟體
- 其他文字輸入欄位

使用前，請先將游標放在目標軟體的輸入位置。

VoiceCapsule 透過各作業系統對應的滑鼠／鍵盤輸出機制，將文字輸入到目前的目標位置。

Linux 目前版本僅支援 X11 環境，Wayland 支援仍在規劃中。Windows 版本則使用 Windows 專用的輸出機制。

不同軟體及桌面環境的焦點管理方式可能不同。如果文字沒有出現在預期位置，請先確認目標輸入欄位是否已取得焦點。

### 文字視窗的右鍵功能

文字輸出視窗提供下列操作：

- 複製選取文字
- 複製全部文字
- 選取全部
- 貼上文字
- 清除文字
- 關閉視窗

可依照需要複製辨識結果，或將文字貼到其他應用程式。

## 10. 常見錯誤與個人字典修正

語音辨識不可能永遠正確。

尤其專業名詞、專有名稱、特殊發音與個人常用詞，容易出現固定的辨識錯誤。

VoiceCapsule 提供兩個字典：

- `common_errors.json`
- `personal_dict.json`

兩個字典使用相同的基本格式，可以由使用者自行增加或修改內容。

### 常見錯誤字典 `common_errors.json`

這個字典適合放置：

- 專業名詞
- 技術名詞
- 軟體名稱
- 程式語言
- 專有名稱
- 容易被語音辨識成其他文字的詞

例如：

```json
{
  "康菲": "ComfyUI",
  "烏班圖": "Ubuntu",
  "拍森": "Python",
  "皮特": "PyQt",
  "吉特": "Git",
  "庫比": "Qubes",
  "裏눅斯": "Linux"
}
```

左側是可能出現的錯誤文字，右側是希望修正成的正確文字。

### 個人字典 `personal_dict.json`

個人字典適合放置使用者自己經常遇到的錯字、誤辨識結果或個人常用詞。

例如：

```json
{
  "因該": "應該",
  "因位": "因為",
  "以經": "已經",
  "戰存黨": "暫存檔",
  "華鼠": "滑鼠",
  "拜給你": "敗給你"
}
```

這些內容可以依照自己的實際使用情況增加。

### 為什麼需要自己增加字典？

每個人的聲音都不一樣。

口音、發音方式、說話速度、語氣、常用詞、個人名稱與專業用語，都可能影響語音辨識結果。

同一個詞，不同的人說出來，辨識結果可能不同。VoiceCapsule 不可能事先知道每個人的特殊發音習慣，也無法只靠程式判斷使用者原本真正想說的是什麼。

因此，使用者可以在實際使用時觀察哪些詞經常被辨識錯誤，再把它們加入字典。

### 如何建立適合自己的字典？

使用流程很簡單：

**說話 → 查看辨識結果 → 找出固定錯誤 → 加入字典 → 後續辨識時依照字典修正。**

基本格式如下：

```json
{
  "錯誤文字": "正確文字"
}
```

例如：

```json
{
  "拍森": "Python"
}
```

不需要為此重新訓練 Whisper 模型，也不必改變自己的說話方式。

**注意：字典修正只會作用於已整合這項功能的辨識流程。目前版本的音訊／影片批次轉錄流程尚未整合字典修正，因此該流程的輸出不會自動套用這兩個字典。**

增加字典時，建議使用具體的錯誤詞組，避免將過於常見的單字設定成全域替換，以免改動原本正確的文字。

## 11. Whisper 模型

VoiceCapsule 使用 OpenAI Whisper 模型系列，透過 Faster-Whisper／CTranslate2 在本機執行語音辨識。

目前提供以下模型：

- small
- medium
- large-v3
- large-v3-turbo

不同模型的差異主要在於模型大小、處理速度、資源需求與辨識能力。

### small

適合一般日常語音輸入。

速度較快，對日常聊天、寫文章、寫筆記及一般語音輸入已經相當實用。

如果不需要使用大型模型，small 可以提供較輕量的使用體驗。

### medium

比 small 更大的模型。

支援多語言語音辨識，也支援 Whisper 的語音翻譯能力，適合希望在速度與辨識能力之間取得平衡的使用者。

### large-v3

large-v3 是大型多語言語音辨識模型，模型檔案約為 3.1 GB。

它的主要優勢是辨識品質。對於重視辨識結果、專業內容或長篇音訊的使用情境，可以考慮使用這個模型。

large-v3 不代表只有高階電腦才能使用。具備足夠資源的一般電腦也能透過 CPU 執行，只是處理速度可能較慢。

### large-v3-turbo

large-v3-turbo 是以較快的轉錄速度為主要方向的模型。

適合：

- 音訊轉文字
- 影片轉文字
- 字幕製作
- 大量語音轉錄

**large-v3-turbo 主要用於語音轉錄，不應作為 Whisper 語音翻譯模型使用。**

### 如何選擇模型？

| 使用情境 | 建議模型 |
|---|---|
| 日常語音輸入 | small |
| 希望兼顧速度與辨識能力 | medium |
| 希望優先考慮辨識品質 | large-v3 |
| 希望快速處理大量音訊／影片 | large-v3-turbo |

模型越大，通常需要更多運算資源，處理速度也可能比較慢，但較大的模型通常有機會提供更好的辨識品質。

實際結果仍會受到錄音品質、語言、口音、硬體及使用情境影響。

## 12. 模型第一次使用比較慢

不論使用哪一個模型，第一次使用時都需要載入模型。

因此，第一次啟動或第一次進行辨識時，可能會比後續使用慢，這是模型載入的正常現象。

模型保持載入時，可以避免後續每次處理都重新載入完整模型。

如果使用者按下「重置記憶體」，模型可能會被釋放。下次使用語音辨識或媒體轉錄時，就需要重新載入模型。

## 13. 模型與硬體

VoiceCapsule 會依照程式的硬體判斷邏輯，選擇適合的執行方式。

具備 NVIDIA CUDA GPU 時，可以使用 GPU 進行運算。

在目前的設計中，約 3.5 GB VRAM 是選擇 CUDA float16 與 CPU int8 執行方式時的重要判斷參考。

實際運算速度會受到下列因素影響：

- CPU 效能
- RAM 容量
- GPU 效能
- VRAM 容量
- 模型大小
- 錄音長度
- 檔案格式及處理方式

**能不能執行模型，與執行速度是兩件不同的事情。**

即使只有 CPU，只要資源足夠，也可以執行較大的模型，只是可能需要更多處理時間。

一般而言，足夠的 RAM、VRAM 及運算能力，有助於提高大型模型的使用效率。

## 14. 中文繁簡轉換

VoiceCapsule 的語音辨識語言與中文介面語言是分開的。

OpenCC 繁簡轉換屬於文字輸出後處理功能。

因此：

- 自動判斷語音來源語言，是語音辨識功能。
- 繁體／簡體中文轉換，是文字後處理功能。

這兩者不是同一件事。

VoiceCapsule 不會因為使用中文介面，就強迫語音輸入只能使用中文。

## 15. 翻譯功能

語音辨識與語音翻譯是不同功能。

### 一般語音辨識

將語音轉換成原本語言的文字。

例如：

- 中文語音 → 中文文字
- 日文語音 → 日文文字

### Whisper 語音翻譯

Whisper 的語音翻譯功能可以將音訊中的語音直接轉換成英文文字。

例如：

- 中文音訊 → 英文文字
- 日文音訊 → 英文文字

VoiceCapsule 可以利用 Whisper 的翻譯能力，將音訊或影片中的語音直接轉成英文。

**注意：large-v3-turbo 主要用於快速語音轉錄，不應拿來作為語音翻譯模型。**

使用翻譯功能時，請選擇支援 Whisper 語音翻譯的模型。

## 17. 隱私與離線優先

VoiceCapsule 的核心語音辨識可以在本機執行。

### 本機模式

- 使用本機 Faster-Whisper 模型。
- 一般語音辨識不需要依賴付費雲端語音服務。

- 使用者不必為了基本麥克風語音輸入訂閱雲端語音服務。

預設使用不聯網模式，重視隱私的使用者可以持續使用本機語音辨識。

使用者應了解所選服務的資料處理方式、隱私政策與計費規則。

**本機模式：資料留在你的裝置。**

**聯網模式：資料依你選擇的第三方 API 服務處理。**

使用者可以依照自己的隱私需求及工作情境，選擇適合的使用模式。

## 18. VoiceCapsule 的主要資料夾

VoiceCapsule 會依照功能將資料分開管理。

| 資料夾／檔案 | 用途 |
|---|---|
| `audio_temp/` | 麥克風錄音、辨識文字與相關暫存資料 |
| `logs/` | 音訊／影片轉錄結果及相關紀錄 |
| `dicts/` | 常見錯誤與個人字典 |
| `fonts/` | 介面使用的字型檔案 |
| `models/` | Faster-Whisper 模型 |
| `ui/icon/` | 使用者介面圖示 |
| `config.json` | 使用者偏好設定，例如主題、模型等 |

### 特別注意

`audio_temp/` 與 `logs/` 的用途不同：

- 麥克風語音輸入的 WAV、TXT 及暫存資料放在 `audio_temp/`。
- 音訊／影片轉錄產生的文字及相關紀錄放在 `logs/`。

處理音訊／影片時，程式會自動清理相關工作暫存，但不會因此自動清空整個 `logs/`。

如需手動清除保存紀錄，可以使用系統設定中的清除存檔按鈕。清除前請先備份重要內容。

## 21. 使用時的重要提醒

使用 VoiceCapsule 時，請特別注意以下事項：

1. 麥克風語音輸入產生的 WAV 與 TXT 存放在 `audio_temp/`，此資料夾只供暫存使用。
2. 使用音訊／影片轉文字時，程式會在每處理完一個檔案後，自動清理相關暫存資料並釋放處理資源。
3. 如果 `audio_temp/` 裡的文字還有用途，請先複製或另存到其他位置。
4. 音訊／影片轉錄結果及相關紀錄存放在 `logs/`，與 `audio_temp/` 分開管理。
5. 系統設定中的清除存檔按鈕會清除相關保存資料，包括 `logs/` 中的檔案。執行前請先備份。
6. 「重置記憶體」用於較完整的資源釋放，不等同於系統設定中的清除存檔。
7. 使用線上 API 前，請確認服務商、API Key、模型、帳號用量及相關費用。
8. 語音辨識結果仍可能出現錯誤。重要文字或正式文件，請自行檢查並保存。

## 結語

VoiceCapsule 的核心其實很簡單：

**不想打字，就說。**

一般語音輸入可以直接將說話內容轉換成文字；音訊與影片也可以透過本機語音辨識轉換成逐字稿和字幕。

常見的專業名詞與錯誤，可以透過字典修正功能改善；而使用者自己的口音、發音方式與常用詞，也可以依照實際使用情況逐步整理個人字典。

VoiceCapsule 重視本機執行、離線優先及隱私，同時提供不同模型與處理功能，讓使用者依照工作、學習與創作需求選擇適合的方式。

它不只是把聲音變成文字，也希望成為一個方便、輕量，能融入日常工作的語音輸入工具。
